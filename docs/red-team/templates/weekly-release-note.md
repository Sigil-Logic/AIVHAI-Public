# Weekly Release Note Template

**Status**: Static artifact  
**Version**: 1.0.0  
**Date**: 2026-10-09  
**Project**: AIVHAI

---

The release manager posts this text, filled in, in `#aria-aivhai-redteam` after pushing a weekly release.  It is short by design.  The detail lives in the release itself, so the message only needs to say where to look.

```text
AIVHAI-Public release YYYY-MM-DD: Sigil-Logic/AIVHAI-Public@<40-hex commit>
Source Sigil-Logic/AIVHAI-Sigil@<short>; upstream pins AIVHAI-Everything@<short>.

New or changed this week:
- <one line per item, naming the file or assurance case>

Known gaps changed: <none | one line each>
Open defeaters changed: <none | one line each>

Cite the commit hash, not the tag.  Reports: SECURITY.md.
```

**For a hand-off release**, add a line naming the hand-off note, `docs/red-team/sprint-N/handoff.md`, and also send the message by e-mail to the Trail of Bits contacts.
